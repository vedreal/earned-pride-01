## The entry

`main.py` writes one line of text (1–240 characters) to `/output/entry.txt`: a quiet, earned moment of pride for someone in a scene.

> The seamstress unpicked the same hem seven times before the wedding dress finally hung straight, and she did not tell anyone.

The program holds ten candidate lines, scores each against the judge's brief — genuine earned pride, a concrete scene, pride earned inside the line, landing in one read, freshness — and writes the highest-scoring one. The seamstress wins: seven unpicked hems, a dress that finally hangs straight, and nobody told. The pride is shown, never announced.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3 only; no dependencies. The output directory can be overridden with the `OUTPUT_DIR` environment variable (defaults to `/output`).
